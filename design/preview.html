The Arena

Style preview for visualising Jake Schincariol's /arena skill. Pixel art in the Claude Code mascot's style, a stone colosseum, parchment UI, blackletter titles. Every sprite on this page is generated from the grids in sprites.js, so colours and builds are swapped at run time.

Builds, one per model

The skill spawns every competitor on the model you are running, so one run is normally one build in many colours. Builds only mix if the run mixes models.

Colour = reasoning mode

There are 15 reasoning modes, one colour each. Pairing avoids two agents with the same reasoning mode, so the two fighters in a duel almost always differ in colour. A 100-agent run uses every colour.

Shield charge = strategy

The card's third part. The shield is painted in the agent's colour. The workflow shows only in the hover card, because a fourth visual channel would be noise at 100 agents.

Weapon tier = attack label

Attackers label every attack MINOR, MAJOR or FATAL. The tier is exact. The weapon inside a tier is random, so a long fight doesn't repeat itself.

States

A real match, replayed

This is match from a generated 100-agent run. The attack titles, concede/rebut stances, scores and judge's reason are read from the run's files. After the loser falls, hover the gravestone to see what killed it.
