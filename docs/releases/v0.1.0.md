The first release of The Arena: a pixel-art colosseum for watching the
[`/arena` Claude Code skill](https://github.com/Jakeschincariol/arena-skill) fight it out, live or as a replay.

## Get started

1. Download `the-arena-v0.1.0.zip` and unzip it.
2. In the project where you run `/arena`, start the viewer: `python3 /path/to/the-arena/viewer.py`.
   It needs Python 3.8 or newer and nothing else.
3. Open http://127.0.0.1:8765.

To look around first without Claude Code, open `the-arena.html` in a browser. It has a demo run
built in, as a replay or as if it were live.

## What's in it

- **Lobby**: write the task, pick the number of competitors, add an answer to beat, and see the
  rounds, sub-agent calls and waves it will cost. Then copy the `/arena` command, or press Start
  if the viewer was started with `--allow-launch`. The lobby opens the run as soon as it begins.
- **Colosseum**: top-down or side view. Competitors loot while they write their first answers,
  then fight: every attack, shield (rebuttal) and heal (conceded and fixed) plays when its file is
  written, with the attack's real label and title. A judge in the crowd holds up the winner, a
  laurel lands on them, and the loser falls.
- **Live and replay**: follow a run as it happens, rewind, go back to live, or replay a finished
  run at up to 8x. The arena feed lists every file as it lands.
- **Fight view**: any match up close, live or replayed, with each fighter's health and log.
- **Results**: the champion's path, the final check against the rejected answer, and the winning
  answer to copy.

## Notes

- The viewer only reads `.arena/`. It never changes your project.
- `--allow-launch` runs `claude -p "/arena …"` with permission to edit files, run `python3` and
  start sub-agents, so a run doesn't stall on approvals. A run costs real tokens: 16 agents is
  91 sub-agent calls, 100 agents is 595.
- A run doesn't record which model it used. Pick the fighters' look with `--model` or the
  Model switch.
