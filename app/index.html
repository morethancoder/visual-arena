The Arena

For the /arena Claude Code skill

Many copies of Claude get the same task and a different strategy. They attack each other's answers, defend and fix their own, and a judge sends one home each match until one is left. Set the fight up here, then watch it. Or enter the colosseum and play it as a game.

New arena

How to write a task that wins

The competitors, attackers and judges see only what you write here, nothing else. Each match is scored on correctness, completeness against the requirements you state, specificity, robustness and clarity. So:

  • Make it stand on its own. Say what the thing is, who it is for and why. Give absolute paths to the files that matter, or paste the data.
  • State every requirement. Length, format, tone, audience, stack, what must not change. The judge can only hold answers to rules you wrote down.
  • Say what done looks like. "A unified diff that passes make check" beats "fix the bug".
  • Ask for the result, not the method. Each competitor gets a different strategy; if you write your own answer in, they all drift toward it.
  • One task per arena. Split "do A, then B, then C" into separate runs.
  • Rejected an answer already? Put it under Answer to beat and say in the task what was wrong with it.
